# Bitcoin Price Prediction

This project predicts Bitcoin prices using Machine Learning and Deep Learning techniques.

## Features
- Linear Regression model
- LSTM model for better accuracy
- Data visualization using matplotlib
- Flask web application

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- TensorFlow (LSTM)
- Flask

## Output
- Future Bitcoin price prediction
- Graph visualization

## How to Run
1. Install dependencies
2. Run the Python files
3. Run Flask app for web interface
